# 📦 pkgapps

A universal, precompiled (`.tar.gz` / `.tgz`) application manager for **Arch Linux**, **Omarchy**, and **CachyOS**, featuring a modern **Omarchy-inspired TUI** with a Cyan-to-Purple TrueColor gradient.

It crawls websites, follows download redirects, validates live archives (HTTP `200`/`206`), renders terminal logo previews using **Chafa** (with native Sixel support for `foot`), and packages apps directly into your own local Pacman repository.

## 🚀 One-Line Automated Setup

To install, manage, migrate, or uninstall `pkgapps` on your system, run:

```bash
curl -fsSL https://raw.githubusercontent.com/MoisesMC2004/pkgapps/main/install.sh | bash
